Data Analytics Internship – Task 18 (Region Performance)

This repository contains my submission for Task 18 of the Data Analytics Internship.

Dataset - Sample Superstore Dataset

Objective - The objective was to compare sales and profit across regions, rank regions based on sales, and understand regional performance.

Tools Used
1. Microsoft Excel
2. Sample Superstore Dataset
3. GitHub

Region Analysis Performed
1. Grouped the dataset by Region
2. Calculated total sales for each region using SUMIF
3. Calculated total profit for each region using SUMIF
4. Ranked regions based on total sales
5. Created a bar chart to compare sales across regions
6. Added key findings to the Excel sheet

Final Results
1. West ranked 1st with total sales of $725,255.64
2. East ranked 2nd with total sales of $678,435.20
3. Central ranked 3rd with total sales of $500,782.85
4. South ranked 4th with total sales of $391,721.91
5. West had the highest total profit of $108,329.81
6. Central had the lowest total profit of $39,655.88

Files
1. Task 18.xlsx - Excel workbook containing the region summary, rankings, chart, and key findings
2. README.md - Summary of the regional analysis

Conclusion - Regional sales and profit were successfully compared using Microsoft Excel. The analysis helped identify differences in performance across the four regions.
